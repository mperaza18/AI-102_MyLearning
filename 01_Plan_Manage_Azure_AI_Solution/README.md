# Plan and manage an Azure AI solution

This section represents the (15 - 20%) according to the official study guide -> [Link](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ai-102#plan-and-manage-an-azure-ai-solution-2025)

The topics evaluated are:

1. [Select the appropriate Azure AI Foundry services](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ai-102#select-the-appropriate-azure-ai-foundry-services)
2. [Plan, create and deploy an Azure AI Foundry service](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ai-102#plan-create-and-deploy-an-azure-ai-foundry-service)
3. [Manage, monitor, and secure an Azure AI Foundry Service](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ai-102#manage-monitor-and-secure-an-azure-ai-foundry-service)
4. [Implement AI solutions responsibly](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ai-102#implement-ai-solutions-responsibly)

In each topic you will find the details services and information that will be evaluated.
